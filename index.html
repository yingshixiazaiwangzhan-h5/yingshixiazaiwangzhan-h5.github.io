六条合法路 · 不踩线的那种

legal.paths原理说明 #
PATH 01

正版订阅 / 单片租借

院线热片、独播剧、纪录片，走持证平台的按次付费或会员。花的钱最后回到创作者和院线分账。

怎么认：页面有《信息网络传播视听节目许可证》编号 + 可开票 + 能申诉下架
PATH 02

公版片库（版权已过期）

作者死亡超 50 年（多数法域）即进入公有领域：《火车进站》《月球旅行记》、早期卓别林、沟口健二部分作品，可合法下载、二创、放映。

怎么认：查版权状态 + 片源标注 PD／Public Domain
PATH 03

CC 授权与开放片库

Internet Archive、Wikimedia Commons、欧洲电影资料馆开放单元、各地影展授权片段——带 BY / BY-SA 标，按署名规则就能用。

怎么认：有明确许可协议文本，不是"网盘里流传的"
PATH 04

图书馆 · 高校 · 资料馆

国家/省级图书馆视听阅览室、电影资料馆修复放映、高校订购的纪录片库，持读者证合法借阅蓝光与数字资源，很多免费。

怎么认：.gov / .edu 域名 + 实体借阅凭证
PATH 05

创作者直供 · 众筹首映

独立导演的 Vimeo On Demand、Patreon、爱发电、B 站充电专属、电影节官方线上展映——钱直接到作者手里，常附导演评论音轨。

怎么认：作者本人账号 + 有明确授权声明
PATH 06

等一等：窗口期与正版碟

很多"想下"只是"想现在就看"。院转网 45–90 天、正版蓝光发行、平台单片上线，忍过窗口期，合法又高清，还带花絮。

怎么认：查官方定档/上线日期，不靠"网传资源"

法律红线 · 五条你以为能躲的，都躲不掉

legal.redlines

刑法217条提供下载链接 = 传播

以营利为目的，未经许可通过信息网络向公众传播视听作品即构成侵犯著作权罪。"我只是在论坛贴了个链接、文件不在我服务器上"——泰州王小虎案、天津法院《肩上蝶》等链接案均已明确：使公众能获得作品，就是传播。

别信："不存片只给链，不算侵权" → 这是被判得最多的侥幸。

最高法司解第10条做榜单/简介 = 应知

对热播影视以榜单、目录、索引、描述性段落、内容简介方式推荐，且公众可在其网页直接下载获得的，法院可认定"应知"侵权。也就是说"我没主动上传"不构成避风港入口。

别信："我只做导航页/资源索引" → 导航热播片恰恰是最重的那项。

避风港不是给盗版站的

避风港保护的是"合法作品 + 单纯管道 + 接到通知立即删"。快播案把话说透了：缓存服务器介入了存储与加速，就不是"断电即失"的临时缓存；明知仍放任，属实行行为，技术中立抗辩不成立。

别信："我是中立技术/避风港免责" → 法院专治这口。

广电总局规定第7/24条无许可证先做视听就违规

从事互联网视听节目服务须取得《信息网络传播视听节目许可证》或履行备案；擅自从事，警告+责令改正+3 万以下罚款，情节严重按《广播电视管理条例》往上走，并可关停网站、吊销许可、停止接入。2025 通辽、开鲁刚罚过。

别信："个人小站没人管" → 行政罚单已经开到县级了。

共犯/帮信不建站也能进去

马鞍山"可可影视"案定了调：域名注册、费用代付、推广引流、资源上传下载，明知侵权仍帮忙的，按侵犯著作权罪共犯或从帮信罪定性。连"只是帮忙推广"都不是安全区。

别信："我只接广告/卖域名" → 流水和主观明知一查一个准。

一宗数罪罚金按获利+数量双算

量刑看传播数量、违法所得、是否含院线预警名单、是否屡犯、是否退缴认罪认罚。从 5 万到 2000 万罚金都有判例；退赃、认罪可从宽，但不退也照样追。违法所得一律没收上缴。

别信："赚得少就不算事" → 泰州那个案子收入几十万，三年实刑起步。

faq

⚠ 这台站为什么故意"什么都不能下"？

因为名字叫"影视下载网站"的，九成是盗版流量站，剩下的正被刑事追。我们把名字接过来，做的却是它的反题：把合法路径和刑事红线摆清楚。全站无资源、无链接、无解析、无跳转，所有按钮 # 占位——你拿去改造成任何商业站之前，请先读完下面几条。

那"网盘转存""离线下载""磁力搜"呢？

同样高危。上海嘉定案就是服务器零文件、纯抓取网盘链接有偿提供搜索，照样 2年8月+120万；"离线下载"本质是把别人的侵权文件存到你控制的服务器再分发，比给链接还重一档。别碰。

用户自己传的，我删得快算不算安全？

网盘案二审给出过相对友好的尺度：对合格通知及时断链、主动设关键词过滤的，只在"未及时处置"范围内担责；但热播期+明知板块+长期不管，天津法院判的是"帮助侵权"。删得快是减损，不是免责金牌。

有没有"绝对安全"的灰色地带？

没有。唯一接近安全的是：只索引公版/CC 授权内容、明确标许可协议、不碰热播院线片、不做榜单推荐、不盈利、接到任何权利方通知 24 小时内下架并留痕。即便这样，也建议先找知识产权律师过一遍架构。

真要做影视产品，合规起步要什么？

①取得《信息网络传播视听节目许可证》或走备案（主体资格门槛高，多为国有控股）②与权利人/集体管理组织签授权合同并留档③内容审核+版权投诉通道+48/24 小时下架 SOP④不接"资源站联盟""解析接口""网盘引流"⑤广告主尽调，拒涉黄赌与盗版导流⑥ICP、公安备案齐全。预算不够就别做"片库"，做影评/活动/资料库更安全。

看到盗版站怎么处理？

不访问、不转发、不下载。可向 12390 扫黄打非举报热线、国家版权局版权执法平台、平台方侵权投诉入口举报；权利人可发合格下架通知并保全证据。
